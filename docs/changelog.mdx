# Changelog

`@cherry-design-system/react` is currently at version `2.0.1`. The entries below follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html). Release notes for `cherry-styled-components` are in the 1.x documentation, under the version switcher.

<Update label="2.0.1" description="2026-11-25">

Navigation with a router: `NavPill` can stick or float, track the current route and in-page sections, and `NavItem` renders your router's link. See [NavPill](/components/nav-pill) and [Installation](/installation#navigation-with-a-router).

<Badge color="green" size="sm">Added</Badge>

- `NavPill` `position`: `"static"` (default), `"sticky"` or `"fixed"`. A fixed pill floats over the page on a translucent, blurred surface and slides in from its edge
- `NavPill` `placement`: `"top"`, `"bottom"`, `"top-start"`, `"top-end"`, `"bottom-start"` or `"bottom-end"` for a sticky or fixed pill (sticky uses only the top or bottom). `start` and `end` follow the writing direction, the distance to the edge is `--cherry-nav-pill-offset` (16px), and the safe-area insets keep it clear of notches and home bars
- `NavPill` `trackRoute`: marks the link for the current URL path as the current page (`aria-current="page"`, the deepest match wins, so `/docs/button` beats `/docs`) and follows client-side route changes in Next.js and other routers. A link's own `active` prop always wins
- `NavPill` `trackSections`: highlights in-page links (`#section`, or `/path#section` on that path) as their section scrolls into view, with `aria-current="location"`. While a section is active it takes the highlight; the current-page link keeps its meaning
- `NavItem` `asChild`: renders your router's link (Next.js `<Link>`, React Router, TanStack) as the item, so clicks navigate client-side instead of reloading the page. The link keeps the item's class, state, icon and tracking
- `useActiveSection(ids)` and `getActiveSection(ids)`: the same section tracking for a table of contents or a docs sidebar
- A sticky or fixed pill offsets anchor jumps so headings never land under it, and a fixed bottom pill reserves room under the page's last content

<Badge color="blue" size="sm">Changed</Badge>

- The README shows npm and license badges, a light and dark component showcase, and release and security sections
- The agent skill documents navigation with a router: `asChild` with Next.js `<Link>`, `active` from `usePathname()` versus `trackRoute`, section tracking and positions (`references/setup.md`), plus a rule that router links go through `asChild`
- `ChatInput`'s `footnote` examples no longer suggest a disclaimer line; the prop itself is unchanged

</Update>

<Update label="2.0.0" description="2026-11-25">

The first release of `@cherry-design-system/react`, cherry's second generation and the successor to `cherry-styled-components`. Components ship static CSS in `@layer cherry` and are styled through `--cherry-*` tokens: no CSS-in-JS, no theme provider, Server Components ready. See [Migrating from 1.x](/migration).

<Badge color="green" size="sm">Added</Badge>

- More than 60 components: form controls (Button, IconButton, ConfirmButton, Input, Textarea, Password, Select, Combobox, Checkbox, RadioGroup, Toggle, Range, NumberField, OTPInput, Dropzone), date and time pickers (Calendar, DatePicker, TimePicker, DateTimePicker), navigation (Tabs, Sidebar, NavPill, Breadcrumb, Pagination, Stepper, Menu), overlays (Modal, Sheet, Popover, Tooltip, SearchDialog, Toast), content and data (Card, Table, StatCard, Avatar, Badge, Tag, Callout, Banner, EmptyState, Progress, Skeleton, Prose, CodeBlock, Snippet), layout primitives (Container, Grid, Flex, Stack) and a chat kit
- Light and dark mode switched by a class on `<html>`, set before the first paint by `themeInitScript`, with a light, dark or system preference (`useColorMode`, `ThemeToggle`) and per-section modes through `data-cherry-mode`. See [Dark mode](/dark-mode)
- Brands from one accent color with `createBrand()`, which derives hover, tint, text and ring shades for both modes as validated plain CSS. See [Brands](/brands)
- WCAG 2.2 AA: checked in CI with axe in light and dark at 1280px and 320px with every popup open, plus focus visibility, focus traps, Windows High Contrast and reflow. See [Accessibility](/accessibility)
- Per-component CSS (`css/<name>.css`), token names in TypeScript (`/tokens`) and `style-api.json`, which lists every class, `data-*` attribute and allowed value. See [Styling](/styling)
- An agent skill in `skills/cherry-react`, generated from the component source, that documents every component, its props and its accessibility. See [Skill for AI agents](/ai-skill)

</Update>
