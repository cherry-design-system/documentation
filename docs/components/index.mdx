# Components

Every component is exported from `@cherry-design-system/react` and styled by one stylesheet. Import `@cherry-design-system/react/styles.css` once at the root of your app, then import components by name. See [Installation](/installation) for the full setup.

```tsx
import "@cherry-design-system/react/styles.css";
import { Button } from "@cherry-design-system/react";

export default function Page() {
  return <Button>Get started</Button>;
}
```
