## Styled Components Helpers

- **[StyledComponentsRegistry](/v1/code/installation)** - Renders CSS in your Next.js app. Imported from `cherry-styled-components/next`.
- **[CherryThemeProvider](/v1/code/installation)** - Wrap your app with the Cherry Theme context.
- **[ClientThemeProvider](/v1/code/dark-mode)** - The full theme provider, with `theme-color` meta sync, for flash-free dark mode in server-rendered apps.
- **[themeInitScript / createThemeInitScript](/v1/code/dark-mode#createthemeinitscript)** - Blocking head script that sets the mode before the first paint.
- **[resolveTheme](/v1/code/dark-mode#resolvetheme)** - Resolve the `theme` cookie to a theme object in server code.
- **[ThemeContext](/v1/code/dark-mode#manual-theme-toggle)** - Access `toggleTheme` and `setPreference` for custom mode controls.
- **[useColorMode / useResolvedTheme](/v1/code/dark-mode#usecolormode)** - Read the mode and preference, or the theme with real color values.
- **[createThemeVariables](/v1/code/theme#createthemevariables)** - Build the CSS-variable theme and its stylesheet, in server or client code.
- **[modes / modeValue](/v1/code/dark-mode#styles-that-differ-by-mode)** - Write a style that differs by light and dark mode.
