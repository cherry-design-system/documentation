# Colors

Every color is a CSS custom property named `--cherry-<token>`, so the swatch labeled `bg-canvas` is `var(--cherry-bg-canvas)`. Use the semantic colors in your CSS: they switch between light and dark mode on their own, and [brands](/brands) re-point them. The palette below is what they resolve to.

```css
.panel {
  background: var(--cherry-bg-subtle);
  color: var(--cherry-fg-default);
  border: 1px solid var(--cherry-border-default);
}
```

<Callout type="note">
  Never branch on the mode to pick a color, and never write `.dark` overrides for a cherry color. Use the semantic token; it already switches. See [Dark mode](/dark-mode).
</Callout>

## Semantic colors

These are the colors to use in your CSS. Each one resolves from a light slot and a dark slot (`--cherry-l-*` and `--cherry-d-*`, see [Brands](/brands#override-the-color-slots-in-css)). Each group shows the light value, then the dark value.

<Callout type="warning">
  Readable text uses `--cherry-fg-default` or `--cherry-fg-muted`. `--cherry-fg-subtle` is below 4.5:1 contrast and is only for disabled text, borders and decorative marks.
</Callout>
